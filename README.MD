# AI-POWERED APPLICATION.

A browser-based AI coaching application designed to help users track their daily performance,review progress, and receive personalized coaching guidance.
## What It Does

- Collects user input through a browser interface.
- Analyzes submitted performance data.
- Displays feedback and coaching recommendations.
- Helps users understand their progress and identify areas for improvement.

## Setup

```bash
pip install -r requirements.txt

```
